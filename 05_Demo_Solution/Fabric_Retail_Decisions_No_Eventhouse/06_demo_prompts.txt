DEMO 1 / FABRIC DATA AGENT ALONE
1. Compare Electronics revenue for September 2025 and September 2026. Return both totals, the dollar change, the percentage change, and the source table names. Use Revenue, not Units.
2. Which stores contributed most to the decline? Show each store's revenue in both periods and rank by absolute decline. Include the store IDs and source tables.
3. How many stores show low inventory in the available snapshot? State the snapshot date and explain whether this proves stock shortages caused the whole-month revenue decline.

FOUNDRY-ONLY SMOKE TEST (NO FABRIC DATA)

Use placeholders instead of numbers. Separate verified observations, hypotheses, unknowns, and proposed actions requiring human approval."

DEMO 2 / FOUNDRY + FABRIC INTEGRATION
Use the first prompt as a fast integration smoke test. Then send the follow-up in the same Playground conversation for the full investigation.

Fast smoke test:
"Use the connected Fabric RetailEvidence agent to compare Electronics revenue for September 2025 and September 2026. Return both totals, the dollar and percentage change, and the source table and periods. If RetailEvidence cannot be queried, say so; do not guess."

Full investigation follow-up:
"Continue the investigation using live results from RetailEvidence. Rank the stores contributing most to the revenue decline. Then examine the available inventory snapshot, promotions, and store operations. Separate verified findings from hypotheses, cite the source tables and periods, explain what the evidence cannot establish, and recommend three actions for a manager to review. Do not execute any actions."

DEMO 3 / NEW EVIDENCE (after running 02_reveal_new_evidence.py)
1. Query the new_evidence table. How many audit observations were found? Summarize them and say whether they change the confidence of the earlier hypotheses. Cite the source table.
2. Produce a revised one-minute decision brief, distinguishing verified evidence, remaining uncertainty, and actions requiring human approval.
